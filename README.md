# Inspiration Compass (prototype)

Clickable prototype of the Leadership Inspirations Compass: nine one-question
scenarios for the leader, their team and their own leader, with the result
shown on a compass built around the Hilti Leadership Framework.

All numbers and team answers in the prototype are illustrative.

## Run it locally
Open `index.html` in any browser. No build step, no dependencies.

## Share it as a link (GitHub Pages)
1. Create a new repository, e.g. `inspiration-compass`.
2. Upload `index.html`, `.nojekyll` and this `README.md` to the `main` branch.
3. Settings → Pages → Build and deployment → Source: *Deploy from a branch*,
   Branch: `main`, folder `/ (root)` → Save.
4. After a minute the site is live at
   `https://<your-account>.github.io/inspiration-compass/`.
